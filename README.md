# 一蓑烟雨 · 苏轼的人间行旅

十幕人生、150个作品条目、同期推荐和资料检索的 GitHub Pages 版。

## 发布

1. 在 GitHub 的 wyp-317 账号下新建公开仓库，名称可用 Sushi。
2. 将本文件夹里的文件上传到仓库根目录，让 index.html 位于根目录。
3. 打开 Settings → Pages，Source 选择 Deploy from a branch，分支 main，目录 /(root)，保存。
4. 部署完成后在 Pages 页面点击 Visit site。仓库名为 Sushi 时，预期网址为 https://wyp-317.github.io/sushi/ 。

网址须在 GitHub 完成部署后才会生效。更新作品资料后，在 Python 项目目录运行 python tools/export_github_pages.py，再重新上传导出的文件。

网页在浏览器中执行筛选。Python 源项目保留 SQLite 后端、数据维护工具和 TDD 证据，可用于课程交付。
